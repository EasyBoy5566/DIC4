# ICEIB 2027 IEEE conference starter
Modular IEEEtran template for the ICEIB 2027 IEEE track. Confirm the final conference-specific format with organizers. The conference site specifies 4--8 pages.

Upload `ICEIB2027-IEEE/` (or sync via Overleaf MCP) to Overleaf, set `main.tex` as the root document, and compile with `pdfLaTeX` + `BibTeX`. Replace the placeholder author block with verified romanized names, departments, and emails before submission. No experimental results are supplied at the proposal/protocol stage.

Local build: `latexmk -pdf main.tex` (with `IEEEtran` and listed packages installed).

- Conference: https://www.iceib.asia/
- IEEE templates: https://www.ieee.org/conferences/publishing/templates.html
