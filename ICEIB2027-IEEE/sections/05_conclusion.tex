\section{Conclusion}\label{sec:conclusion}
% =====================================================================
This paper presented an evidence-traceable domain-specific agent that combines single-room temperature--humidity sensing, township forecasts, versioned rules, and user feedback to support everyday decisions about appliances, outings, and laundry drying. The design keeps computation in deterministic Python code and limits the LLM to intent parsing, allow-listed tool routing, and explanation, binds every recommendation to an evidence record, and degrades to clarification, abstention, or a template fallback when data or explanations cannot be verified. Its event-triggered feedback loop collects time-aligned operation labels under an explicit query cooldown and keeps unknown and mixed operations distinct.

The contribution at this stage is the system architecture, formal data and evidence model, and a leakage-free evaluation protocol with event-grouped temporal splits. Measured deployment results, baseline comparisons, and ablation findings are not yet available; executing the two-week single-room study is the immediate next step. Future work will extend the study to multiple rooms and seasons, add air-speed and radiant-temperature sensing, and examine closed-loop appliance control.
